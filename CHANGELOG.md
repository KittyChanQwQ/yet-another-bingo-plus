### 1.3.0-beta.2

- Fixed the HUD still rendering when F1 is pressed

- Added an option to hide the "Bingo!" quick-start button on the title screen

### New Features:

- Added a small countdown period before the game starts (configurable in `game-options.json`)

- Added custom sounds for item scores, game win/lose, and the start countdown!

- Moved the `/bingo set ...` commands to `/bingoprefs ...` to separate them from the game settings

- Support for 1.20.5!

- Added [Armadillo Scute](https://minecraft.wiki/w/Armadillo_Scute) and [Wolf Armor](https://minecraft.wiki/w/Wolf_Armor) to the default tier lists! (1.20.5 only)

### Bugs Squashed:

- Fixed team spawn kit chests not being created when `/join` is used mid-game
