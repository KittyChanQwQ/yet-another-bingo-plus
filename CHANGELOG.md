### New Features:

- **Play multiple cards in one game!** This is done with a new "Cards" menu, which can either be a number or "Infinite". ([#73](https://gitlab.com/horrific-tweaks/bingo/-/issues/73))

- **Integration with [Simple Voice Chat](https://modrinth.com/plugin/simple-voice-chat)!** ([#100](https://gitlab.com/horrific-tweaks/bingo/-/issues/100)) Players will be moved into a group for each team at the start of the game.

- Removed the confusing "Ranked Mode", and replaced it with a more descriptive "Win Behavior" menu on Page 3.

- Added a "Scores" tab to the end screen that lists all teams/scores by rank. ([#103](https://gitlab.com/horrific-tweaks/bingo/-/issues/103))

- Support for [server-side goal icons](https://gitlab.com/horrific-tweaks/bingo/-/issues/93) and [customizing the lobby menu orientation](https://gitlab.com/horrific-tweaks/bingo/-/issues/101)

- Added a couple new 'challenge' objectives!

### Bugs Squashed:

- Fixed spectators being able to interact with inventories when Vanish is installed

- Fixed player spawn kits not being recreated after death

- Fixed respawn anchor using two charges at once ([#110](https://gitlab.com/horrific-tweaks/bingo/-/issues/110))
