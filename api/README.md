# Module api

## Yet Another Bingo API

The Yet Another Bingo API provides info to other mods about the current game, team scores, and player statistics.

Broadly, this allows for supported integration points without the risk of breaking changes between each mod release. If
there is functionality you need that isn't provided here, but can be easily exposed, please open an issue or a PR
in the [repo](https://gitlab.com/horrificdev/bingo)!

To get started with the API, see the intro guide at [https://horrific.dev/bingo/api/overview/](https://horrific.dev/bingo/api/overview/).
