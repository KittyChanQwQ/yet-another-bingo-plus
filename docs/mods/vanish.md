# Vanish

The [Vanish mod](https://modrinth.com/mod/vanish) allows certain players to be invisible to anyone else in the game. This is useful for spectators to fly around in adventure mode, where they can see each team's bingo card on their hotbar.

When Vanish is installed, the bingo mod will automatically vanish any players that aren't on a team, and put them in adventure mode instead of spectator.

::: warning Note:
While vanished players will be invisible to other players in the game, they are *not* invisible to operators by default!

To change this, you'll need to configure [LuckPerms](./luckperms) and set the `vanish.feature.view` permission to `false`.
:::
